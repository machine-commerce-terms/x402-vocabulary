# x402 vocabulary

A shared vocabulary for why x402 calls fail, ordered by the stage at which the call stopped, from the first unpaid call to delivery after payment. It is meant to be used by anyone who measures x402 calls, so that two usages of the same word mean the same thing.

- [The vocabulary](VOCABULARY.md): terms, principles and failure modes. Current version: 1.0.
- [Changes](CHANGELOG.md)

## How this list is kept

- Maintained by [nohumans.directory](https://nohumans.directory) and [probe402](https://probe402.com). Either can propose a change; it goes in when both agree.
- Where the two define something differently, both definitions are shown.
- Each version is numbered and comes with a list of what changed. A failure mode keeps its number.
- Anyone who measures x402 calls is welcome to use the list, and to publish counts against it.
- Licence: [CC-BY 4.0](LICENSE).
- The list holds terms, principles and failure modes only: no figures and no data about any seller. Each maintainer publishes its own numbers under its own name and cites the version it used.
- Once both maintainers have cited a numbered version, the list is offered to the x402 Foundation as a proposed vocabulary. If the Foundation accepts it, the list moves there.
